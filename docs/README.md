# Documentation

This index routes readers to authoritative Faktory MVP contracts and their implementation status. Repository sources do not authorize deployment or prove a deployment or pipeline run.

| Document | Covers |
| --- | --- |
| [Architecture](architecture/README.md) | System, v2 projects, model releases, dependencies, protocol, storage, access, and telemetry contracts. |
| [Operations](operations/README.md) | Destructive migration, runtime recovery, telemetry operation, storage, deployment, and release procedures. |
| [Quality](quality/README.md) | Project, dependency, migration, render, access, and full local coverage requirements. |

The protobuf source is the wire authority. Architecture documents define behavior not expressible in protobuf, including authentication, HTTP geometry delivery, object layout, concurrency, and failure semantics.
